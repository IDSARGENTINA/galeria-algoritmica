# 🎨 Galería Algorítmica | Instituto Data Science Argentina

Proyecto interactivo que explora la intersección entre la inteligencia artificial y la creatividad humana.

## 🚀 Experiencias Disponibles

### 📸 Opción A: Retrato Algorítmico
Sube tu foto y transforma tu rostro en una obra de arte digital usando **InstructPix2Pix**.

### 🎨 Opción C: Poema Visual
Escribe una palabra o frase y genera arte abstracto único con **Stable Diffusion 2.1**.

## 🛠️ Tecnologías
- **Frontend**: Streamlit
- **Backend de IA**: Hugging Face Inference API
  - InstructPix2Pix (edición de imágenes)
  - Stable Diffusion 2.1 (generación de arte abstracto)
- **Integración**: WordPress (vía iframe)
